## Calendar probe

**OBSERVED:** the configured public Nasdaq earnings endpoint accepts one `date`
query per day and returns rows under `data.rows`. A row can contain a date but
`time` can be `time-not-supplied`; it is not safe to turn that into a trade time
implicitly. Reverb therefore requires `config/calendar.json` to provide an
explicit `default_event_time_et` before a date-only event can schedule work.
This is calendar plumbing, not Bitget product evidence, and the reporting-time
assumption remains **ASSUMED** until verified from a first-party event source.

## Raw evidence and reproduction

`python3 scripts/probe.py capture` stores raw public HTTP response bodies and
appends their metadata to a hash-chained evidence ledger. Every run snapshots
the exact config. `python3 scripts/probe.py report` verifies hashes and computes
[measurements](measurements.md) from the most recent captured run. Failures stay
in the ledger and make capture exit nonzero; successful independent requests
are retained for diagnosis. No authenticated response or secret is published.
